Run the verifier

Check the machine before you trust it: the verifier prints PASS or FAIL.

From your laptop

$ curl -sSLO https://odile.fyi/odile-verify.tar.gz
$ tar xzf odile-verify.tar.gz
$ cd odile-verify && ./odile-verify https://demo.odile.fyi --expect {{MEASUREMENT}}

The number after --expect is this machine's measurement: the measurement row above. The verifier needs Python 3 and the openssl binary.
